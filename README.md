# TradPlus Moloco Adapter Swift Package

Swift Package Manager support for the TradPlus Moloco adapter (15.14.0).

## Installation

```text
https://github.com/tradplus/TradPlusAdSDK-SPM-Moloco.git
```

```swift
.package(url: "https://github.com/tradplus/TradPlusAdSDK-SPM-Moloco.git", exact: "15.14.0")
```

Third-party dependency: Moloco SDK `4.9.1`.

## Notes

- This package automatically resolves `TradPlusAdSDK` 15.14.0.
- Add `-ObjC` to the app target's `Other Linker Flags` if required.
